# The November Ledger

A record of the November 2026 outages: every incident found, the cause each organization gave in its own words, and the dated events around them, traced back month by month to January 2025.

- `ledger/index.html` and `ledger/ledger.json`: the published page and its 205-row incident ledger.
- `research/`: raw research output. Pass 1 holds the sweep, 32 dossiers, 141 context events and four analyst lenses. Pass 2 holds the 9 core dossiers, the monthly patch-volume series and the outage census. Pass 3 holds the fact-check verdicts. The last file holds the cause classification of each ledger row.

Compiled 21 November 2026 from public sources. Every row carries its source URLs.
